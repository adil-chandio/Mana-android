# MAYA — Privacy Policy

**Effective:** 2026-10-19 · **Version:** 5.12.0

MAYA ek personal AI assistant hai jo AAP KE PHONE par chalti hai. Is ka
usool aasan hai: **aap ki zindagi aap ki hai.**

## Kya data hota hai aur KAHAN

| Data | Kahan rehta hai | Koi aur dekh sakta hai? |
|---|---|---|
| Chat, facts, diary, ledger | Sirf aap ke phone (localStorage) | Nahi |
| API keys (Gemini/Groq/Fish…) | Sirf aap ke phone (settings) | Nahi — kabhi cloud par nahi |
| Settings backup file (📦) | Aap ke Download folder | Sirf jis ke paas file ho |
| Memory cloud backup (☁️) | GitHub repo /memory/ — **AES-GCM encrypted** | Ciphertext — code ke bagair bekaar |
| NTFY alerts (🔔) | ntfy.sh topic par (optional, default OFF) | Sirf jo topic jaane (topic = aap ka raaz) |
| Screen reading (NAZAR) | Phone par hi process hoti hai | Nahi |

## Third-party services (jab AAP chunein)

- **AI brains** (Gemini, Groq, Cerebras, Mistral, Pollinations…): aap ka
  sawal un ko jata hai — jawab ke liye. Yeh un ki apni privacy policies ke
  tehat hain. Keys optional hain; keyless mode bhi chalta hai.
- **Voice** (Fish Audio, Edge TTS): sirf bolne ke liye text jata hai.
- **ntfy.sh** (optional alerts): sirf woh paighaam jo Maya khud bheje.
- **GitHub** (optional backup): sirf encrypted memory blob.

## Jo KABHI nahi hota

- Koi account banana, koi login, koi analytics, koi ads
- OTP/password fields parhna (automation khud inhein chhuti hai)
- Bina ijazat koi call/SMS (TRUST MODE bhi aap ka faisla hai)
- Data ki kharidari/farokht — aap ka data bechna

## Ijazaatein (kis liye)

Mic (sunne ke liye) · Notifications (alerts) · Contacts (phone book se
naam — sirf jab kaho) · Accessibility (screen parhna/taps — optional) ·
Install packages (updates) · Battery-unrestricted (wake word).

## Bachon ki privacy

13 saal se kam ke liye nahi hai.
